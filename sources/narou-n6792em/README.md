## Что есть

[`catalog.json`](catalog.json) — метаданные с 113 порядковыми номерами и каноническими адресами, без текста произведения. Первая страница оглавления Narō показывает эпизоды 1–100; ссылки 101–113 построены по формату URL и требуют независимой сверки с недоступной в рабочей среде второй страницей. Пока нет полученного от автора исходного корпуса, не отмечать эти главы как загруженные или проверенные.

## Как собрать предоставленный автором исходник

Положить законно полученные отдельные японские тексты в локальную папку `raw` с названиями `001.txt` ... `113.txt` и выполнить:

```bash
python -m unittest discover -s tools/novel-ingest -p test_pack_author_source.py -v
python tools/novel-ingest/pack_author_source.py \
  --catalog sources/narou-n6792em/catalog.json \
  --raw-dir /path/to/authorized/raw \
  --output out/narou-n6792em-001-113.zip
```

Упаковщик работает **без сети**, проверяет состав 113 файлов, порядковые номера, ссылки, пустые/повторные тексты, контрольные суммы, сохраняет 113 TXT, `combined.txt` и `manifest.json` в архив. Не подтверждает права на публикацию.
